# Windows application

## Direction contract

THESIS: A student opens WinKu to ask, study and revisit an explanation. Chat remains the primary workspace; document reading appears only when a file is opened.

OWN-WORLD: Android is the visual authority. Synchronize its color roles, launcher and in-app W from native sources; retain neutral grey/chalk surfaces, ink text, neutral chrome actions, emerald business accents, rounded bubbles and composer. Learning output directly reuses Android bodies and LearningWebView role overrides. Windows keeps its system study typography and desktop layout adaptations. No change to the Android identity.

STORY: Add a provider once, ask a question, attach a source when needed, and continue the same local conversation after reopening. Model access is configured explicitly by the user.

FIRST VIEWPORT: A 240px history sidebar with the Android-derived WinKu AGENT heading and neutral new-chat action. An empty conversation centers the in-app W, “今天想做点什么” and rounded composer; missing-model configuration keeps its direct settings action. Established conversations use a centered reading column and bottom composer, uniform right-aligned user bubbles and unbranded assistant prose. Tools remains an empty student tools entry pending user content.

FORM: User-pinned chat-first composition, with a document panel opened on demand. Windows retains a collapsible sidebar, drag-and-drop, keyboard controls and inset expansion with Escape and focus handling. No structural lottery applies to this specified extension. Light and dark roles are generated from Android; learning content has its own Android-matching scope rather than inheriting chrome action roles. The workspace clips overflow to keep header and composer stable during content focus and scrolling.

FINISH: End with independent review, the verdict, refreshed DESIGN.md and sidecar, and provenance for every shipping raster. Evidence for this unification is in .review/unified-*.png and current source. Android screenshots under apps/android/build/conversation-actions-review are existing references; this desktop pass does not claim a new physical-device Android test.
