# Windows application

## Direction contract

THESIS: A student opens WinKu to ask, study and revisit an explanation. Chat remains the primary workspace; document reading appears only when a file is opened.

OWN-WORLD: Inherit the Android learning UI: neutral grey and chalk surfaces, ink text, emerald W mark, restrained rounded controls, locally rendered textbook mathematics and highlighted code. No change to the Android identity.

STORY: Add a provider once, ask a question, attach a source when needed, and continue the same local conversation after reopening. Model access is configured explicitly by the user.

FIRST VIEWPORT: A 240px history sidebar, quiet native window chrome, a centered reading column, and a bottom composer. First launch explains the missing model configuration with one direct settings action. Tools remains an empty student tools entry pending user content.

FORM: User-pinned chat-first composition, with a document panel opened on demand. No structural lottery applies to this specified extension. System Windows typography serves long study sessions under ordinary desk lighting; light and dark themes follow the user's choice.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
