## Direction contract

THESIS: Bring the Android WinKu application to Windows with the same page hierarchy, control vocabulary and chat flow. The user's Android screenshots override the previous desktop approval.

OWN-WORLD: Android Color.kt, Brand.kt and vector drawables are authoritative. A 300 logical-pixel sidebar, native-derived icons, grouped R20 settings rows, a R28 composer, emerald W and prompt-polish wand. Empty chat centers W and title above composer. No large first-run model setup panel. Task creation opens a chat draft; the real dsh automation tools request authorization. Windows schedules run only while app is open, with one catch-up after reopening. No claim of Android-exclusive services on Windows.
