# 提示词润色

Android 输入栏模型选择左侧提供 34dp 魔法棒按钮，与发送键同尺寸。内置规则位于 `apps/android/app/src/main/assets/skills/prompt-polish/`，参考来源与 MIT 许可随 APK 保留在 NOTICE 中。

## 行为

- 仅处理当前草稿，不带聊天历史、不读取附件内容、不调用 Agent 或其他工具、不自动发送。
- 使用当前模型与服务商，复用现有的密钥、自定义请求头及 Chat Completions / Responses / Messages 协议选择。不会切换其他服务商或模型。
- 单次非流式请求，输出上限不超过 2048 tokens，按用户模型上限进一步收紧。仅在已声明对应控制方式时降低推理强度；不向未知服务商猜测发送开关。
- 最长输入 8000 字符；连接超时 5 秒、读取超时 15 秒、总超时 20 秒。不自动重试，避免重复计费；失败可手动重试。
- 仅完整、非空的最终文本可以写回。截断、工具调用、超长结果、链接/引用/代码丢失均保留原稿。
- 成功后禁止对同一草稿重复润色，并提供撤销。手动修改文字后恢复；发送清空、会话离开或模型变化会使在途结果失效。
- 草稿用递增修订号保护，修改后即使又改回相同文字，旧请求也不能覆盖；每个会话分别保存状态。

## 验证

单元测试：`PromptPolishTest` 覆盖三种协议的请求/响应、截断拒绝、引用保真与推理参数；`PolishDraftTest` 覆盖修改后回退、旧请求与新请求竞争、撤销失效。

```powershell
cd apps/android
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug "-Pdsh.fetchShizuku=false" --console=plain
```

发布前需在真实设备补验：窄屏/大字体/深浅色布局、成功与撤销、重复点击、等待时编辑/发送/切会话、无模型/断网/超时，以及真实服务商的完成延迟。2–4 秒只是短提示词的体验目标，不是已测性能。
