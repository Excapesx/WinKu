# DSH Ultra：安装与使用

安装包：`out/DSH-Ultra-v0.3.8-fix1-arm64.apk`。应用名 **DSH Ultra**，版本 `0.3.8-learning.1`（版本号 27），支持 Android 10 及以上的 arm64 手机。需要较新的 Android System WebView（打包脚本目标为 Chrome 100）；如果系统很旧，请先更新 WebView。

本次修复了首版漏打包 `libc++_shared.so` 的问题。引擎在调用 Node 前就需要加载此 C++ 运行库，缺失会导致引擎进程退出，界面报告 `EPIPE (Broken pipe)`。新版与首版包名、签名一致，直接覆盖安装即可保留模型配置与对话；无需卸载。打包脚本现从上游原生库清单导入全部依赖，并对 APK 内实际 ELF 文件检查依赖是否齐全。

## 安装

1. 将 APK 复制到手机，用文件管理器打开，按系统提示允许该来源安装应用。
2. 安装后打开应用。此包使用调试签名，包名为 `io.github.jackwener.dsh.learning`，可以与原版 DSH 同时安装。
3. 使用对话模型前，另行完成账号及模型服务商配置。安装本身不提供账号、API 凭据或模型额度。

## 先离线试用

在登录页点击 **交互学习**，或打开 **设置 → 交互学习**。示例无需登录、启动 agent 或授予手机工具权限，可体验函数、流程图、图表、小测验、公式、表格、代码和隔离 HTML 八类组件。

- **函数**：双指缩放，拖动画布平移；点击表达式编辑，可添加、隐藏、显示或删除函数。添加参数后，可改数值及最小值、最大值、步长；点全屏扩大绘图区。
- **小测验**：选答案后检查，可查看提示与解析，再重试。
- **其他组件**：流程图支持平移缩放；图表支持查看数据；表格可排序、横向滚动；代码可复制。

## 在对话中使用

完成服务商配置后，可以说：“用可交互函数解释二次函数，让我调整 a 和 b”，或“用流程图和小测验帮我理解这个概念”。模型需要输出完整、有效的围栏数据块，组件才会显示；不完整或无效内容会保留为 Markdown。

对话内点击 **结合我的操作讲解**，才会把当前函数、参数、视图或答题状态发送为后续消息。拖动、缩放不会逐次发送。离线示例没有活动对话，因此不显示此操作。交互状态保存在本机，普通视图与全屏共用。

## 当前验证范围

电脑上的开发预览（`-Pdsh.learningPreview=true`）启动后进入真实聊天主界面，使用明确标记的本地示例对话，无需登录或输入 API Key。开发预览不发起模型调用。完整应用界面的浏览器查看地址为 `http://127.0.0.1:4174/`；原生界面编辑与预览方式见 [实时预览说明](LIVE-UI-PREVIEW.zh-CN.md)。

arm64 APK 构建及相关单元测试通过；修复版另通过原生库完整性及 ELF 依赖检查，新增回归测试会拒绝缺少 C++ 运行库的首版 APK。Android 16 模拟器此前已验证真实双指缩放、状态恢复，以及浅色、深色、全屏、1.3 倍文字、测验和流程图画面。模拟器使用仅含渲染器的 x86_64 诊断版本，未验证 arm64 Node agent。尚未在实体 arm64 手机、实际模型对话、TalkBack 或输入法上完成验证。

Android lint 未通过：28 个错误均位于未修改的 v0.3.8 代码，另有警告和提示；详见 [技术说明与验证记录](INTERACTIVE-LEARNING.md)。此版本未接入 `dsh-pocket` 远程传输，也不提供 ChatGPT 的全部服务。
